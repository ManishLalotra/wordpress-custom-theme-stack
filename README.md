# wordpress-custom-theme-stack

> Modern custom WordPress theme development stack with Gutenberg blocks, REST API health endpoints, security hardening, and Docker Compose environment.

## Overview
A production-ready WordPress engineering stack featuring a bespoke theme with security header enforcement, XML-RPC hardening, custom REST routes, and Dockerized local development with Nginx and MySQL 8.0.

## Features
- Custom WordPress theme (`manish-enterprise`)
- Security hardening (removes generator tags, disables XML-RPC, strict headers)
- Custom REST API health & telemetry endpoint (`/wp-json/enterprise/v1/health`)
- Docker Compose development environment with Nginx & PHP 8.2-FPM
